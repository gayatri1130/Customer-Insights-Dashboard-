# Customer Insights Dashboard Project

## Overview

This project focuses on analyzing customer data to gain valuable insights using a combination of tools and techniques. The dashboard provides a comprehensive view of customer activity, including total customer count, active customer count, and the percentage of active customers.

## Tools and Technologies Used

* **Power BI:** Used for data visualization, dashboard creation, and generating key performance indicators (KPIs).
* **Excel:** Likely used for initial data handling, cleaning, or as a data source for Power BI.
* **SQL:** Employed for querying, manipulating, and extracting data, indicating a structured database was involved.

## Key Processes

* **Data Cleaning:** Raw data was processed to ensure accuracy, consistency, and completeness. This step is crucial for reliable analysis.
* **Data Modeling:** The data was structured and relationships were defined within Power BI to create an efficient data model for analysis and visualization.
* **Data Analysis:** SQL queries and Power BI functionalities were used to analyze customer behavior and identify key trends.
* **Dashboard Creation:** An interactive dashboard was developed in Power BI to present the analyzed data in a clear and understandable format. Key metrics displayed include:
    * **Total Customer:** The overall count of customers.
    * **Active Customer:** The number of customers who have engaged in a specific activity (the definition of "active" would be detailed in the full project documentation).
    * **% Active Customers:** The percentage of active customers out of the total customer base.
